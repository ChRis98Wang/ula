ULA-FM 网络结构与训练流程

当前目标是无视觉头的语言动作模型：输入文本、情绪、动作风格和语义标签，生成 V2 机器人上肢关节轨迹。 训练核心不是“复读视频”，而是学习情绪表达下的连续动作分布。

从 Legacy 条件向量到 MMDiT-lite

当前 1M checkpoint 使用全局条件向量注入；新分支保留 Flow Matching 训练目标，但把 Kimodo 语义改成 token， 让行为和情绪在 Transformer 内部反复参与注意力。

当前 ULA-FM legacy

文本、情绪、风格、gesture、Kimodo behavior/emotion 被压成一个 136D condition。 这个向量经过 MLP 后加到每个 motion frame token 上，然后 motion tokens 做 self-attention。 这种方式稳定、训练快，但语义容易平均化。

condition vector -> MLP -> additive conditioning motion tokens only self-attention architecture: ula_fm_legacy

新分支 ULA-MMDiT-lite new

仍然从噪声轨迹学习到真实动作的速度场，但 condition 不再只作为一个全局偏置。 模型先把 Kimodo 条件投成多个 semantic tokens，再和 motion tokens 拼接做 joint attention， 最后只取 motion tokens 预测关节速度。

condition vector -> semantic tokens [semantic tokens + motion tokens] joint attention architecture: ula_mmdit_lite
Kimodo 语义输入 behavior_id、emotion_id、行为族、upper_body_only 和自由文本 hash embedding。
Joint Attention semantic tokens 与 noisy motion tokens 一起进入 Transformer；行为语义可以影响每一帧动作。
Flow 输出不变 输出仍是 [T, 15] motion velocity，训练 loss、采样、MuJoCo 预览链路保持兼容。
Kimodo 新训练建议配置 保留 legacy，新增 ula_mmdit_lite

下一步：音频接入

音频不替代文本，而是补充节奏、语速、停顿和强弱变化，让动作和说话同步。

接入方式

  • 先使用冻结语音编码器提取 prosody/rhythm 特征。
  • 训练一个小的 audio adapter，把音频特征并入 condition fusion。
  • Action Expert 不需要重写，只需要多一个音频条件通道。
Audio语音能量、节奏、停顿
->
Speech Encoder冻结或轻量微调
Prosody Adapter对齐动作频率
->
Condition Fusion文本 + 情绪 + 音频
Sync Loss动作能量跟随语音节奏
->
Action Expert生成同步上肢动作

训练流程

训练使用 LeRobot parquet 数据。每个样本是一段清洗后的 V2 上肢轨迹，加上对应语义和情绪条件。

1

读取样本

从 clean parquet 取动作窗口和文本条件，动作已经按新版 URDF 重定向并清洗。

2

构造 Flow 任务

随机采样噪声和时间 t，让模型学习从噪声轨迹走向真实轨迹的速度。

3

更新可训练模块

只更新条件融合层、Action Expert、duration head 和 transition head。

4

定期验证

每隔固定 steps 生成长程动作，用 MuJoCo 录制，检查跳变、翻转、穿模和情绪连贯性。

主要损失

  • Flow loss：生成轨迹的速度场是否接近真实动作方向。
  • Planner loss：动作持续时间和情绪转场是否合理。
  • Joint limit clamp：推理时保证关节不越界。

推理方式

  • 输入一句文本和情绪状态。
  • 模型先估计持续时间与转场。
  • Action Expert 从噪声积分生成整段动作。
  • 输出 CSV，并用 MuJoCo 渲染为机器人视频。

周报要点

这页只用于说明方案：现在先把文本和情绪做好，后续把音频作为并行条件接入同一个动作生成器。

当前版本

  • 无视觉头，只做文本/情绪到上肢动作。
  • 语言头冻结，训练 Action Expert 和规划头。
  • 输出用 V2 机器人和 MuJoCo 检查动作质量。

下一阶段

  • 加入音频节奏和语气条件。
  • 让动作长度、转场和语音自然同步。
  • 保留同一套 Flow Matching 动作生成框架。

周报结论：网络主体已经确定，关键质量指标是动作连续性、左右一致性、关节不翻转，以及长程情绪表达是否自然。
