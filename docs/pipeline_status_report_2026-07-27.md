# 机器人上半身动作生成项目 — 路线与当前进度

日期：2026-07-27

## 一、总体路线

```
真实动作数据采集 (BEAT2 / InterAct / Motion-X++ / Xsens)
        -> 3D 人体骨架
        -> 重定向到机器人上半身 URDF 关节 (V2 18D 接口)
        -> 数据质量审核 + 人工盲评 + 溯源锁定 (QC 通过 ≠ 训练准入)
        -> 打包为标准数据集 (LeRobot Parquet 格式)
        -> Flow Matching / MMDiT 生成模型训练
        -> 文本条件动作生成 + MuJoCo 仿真验证 / 机器人执行
```

当前主线接口是 **V2 18D**（15 个上肢关节 + 3 个头部关节），替代了早期 2026-05 规划中的 11/15 关节方案。

## 二、各阶段现状

| 阶段 | 现状 | 说明 |
|---|---|---|
| 数据获取 | ✅ 已完成，规模真实 | BEAT2 语音-手势数据 6,462 个文件（约 12GB）、Motion-X++ HAA500 13,891 个文件（约 855MB）、InterAct 双人交互数据、Xsens 校准数据，均已下载并建立目录清单 |
| 重定向 | ✅ 工具链完整，已产出真实结果 | 基于 GMR/Mink IK 求解器，覆盖 BEAT2、InterAct、Motion-X++、Xsens 等全部来源；已有 199 组真实重定向产物和 16 个 MuJoCo 预览视频 |
| 数据质量审核 | ✅ 体系完整，机制严格 | 40+ 个脚本覆盖"构建盲评队列 → 渲染视频证据 → 人工评审 → 归一化/合并/终裁 → 训练准入裁决"全流程；采用双人评审+第三方仲裁、哈希锁定防篡改、评审时对标签盲评（避免标签泄漏影响判断）等机制。物理 QC 通过不等于训练准入，需独立人工复核 |
| 数据打包 | ✅ 已产出可用数据集 | 采用 LeRobot 标准 Parquet 格式（`datasets/kimodo_lerobot_mmdit_lite`），含语义索引、任务描述、episode 元数据，可直接加载训练 |
| 训练 | ✅ 已有真实训练产出，仍在迭代 | 详见下方"当前两条模型线" |
| 推理 | ✅ 已验证端到端可用 | 文本输入 → Qwen 语义编码 → 行为/情绪分类 → 生成关节轨迹 → MuJoCo 仿真播放，全流程在真实 GPU（RTX 5090）上跑通 |

## 三、当前两条模型线

### 1. BEAT2 18D 正式训练线（当前推荐，仍在推进）

- 最新完整候选：`beat2_18d_from_scratch_formal_v3`，训练 60,000 步，验证集 loss 49.96
- 数据来源、审核状态、许可协议均做了哈希锁定溯源（provenance lock），拒绝任何未经复核数据参与训练
- 今天（07-27 前一天）刚有新一轮诊断实验（v4_diag），尚未达到 v3 的训练完整度，暂不作为替代
- 目前尚无"输入一句话直接生成一段动作"的便捷命令行工具，仅有"从已完成推理结果组装验收视频"的工具

### 2. Kimodo/Qwen 15D 部署线（已可交互使用）

- 已完成 5,000 步训练，配合 Qwen 语义适配器（行为分类准确率 96.3%，情绪分类准确率 93.2%）
- 已实测验证：给定中文文本指令（如"开心地跟主人点头并在胸前挥手打招呼"），可实时生成 150 帧、15 自由度的机器人上半身轨迹，并在 MuJoCo 中播放
- 是目前唯一可以端到端交互式演示的模型线

## 四、质量与测试情况

- 项目自带约 866 个自动化测试，在正确的运行环境下**全部通过**
- 抽查的实时验证（非仅测试）：数据打包读取、训练 checkpoint 加载校验、真实文本到动作生成，三项均在真实环境跑通并产出真实数值结果

## 五、需要关注的风险 / 待办事项

1. **BEAT2 数据许可存在表述冲突**：HuggingFace 元数据标注为 Apache-2.0，但官方项目页面声明为"非商业用途"。当前训练流程要求人工在冲突情形下显式确认"仅限非商业研究用途"才允许使用，这一确认已记录在训练产出的溯源信息中。**如果未来涉及商业化，需要重新核实该数据集的使用授权**。
2. BEAT2 18D 正式线目前没有面向单条文本的便捷生成/试用入口，只能通过完整的验收流程查看效果，若要对外演示需要先补一个轻量生成工具。
3. 部分历史文档（项目结构说明等）曾经引用一台已停用的旧开发机路径，已在本轮梳理中修正为当前实际路径。

## 六、总体结论

从数据获取到最终推理的全链路已经跑通，且有真实产出（不是空脚手架）：真实规模的原始数据、真实的重定向与质量审核记录、真实的训练 checkpoint、真实的端到端推理结果。当前主要工作重心是把 BEAT2 18D 正式训练线推到可对外演示的完整度，并补齐它的便捷推理入口。
