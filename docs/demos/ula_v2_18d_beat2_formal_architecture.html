第 2 章 · Training

从纯高斯噪声，学会还原一段真实动作

整条训练只有一种模式：flow matching + 物理导数正则。没有语义/情绪监督，没有蒸馏 teacher，没有 warm start。 每一步都是同一个循环：抽一条真实 episode → 混合噪声 → 前向 → 算 7 项加权损失 → 反传。

Training step

单步训练数据流

native variable-length batching：不同长度桶（48…512 帧）分别打包，禁止裁剪或定长补齐。

第 4 章 · Inference

从噪声到轨迹：Euler 积分怎么走

推理不是一次前向。模型学到的是速度场 vθ(x_t, t, c)，真正的轨迹要用这个速度场把一段纯噪声， 沿着 t: 0→1 逐步积分回真实动作分布。

Noise → trajectory

采样流程

默认 24 步 Euler 积分；实测 24 步和 100 步结果几乎一致，采样步数不是当前输出质量的瓶颈。

I1 · CONDITION264D

选一个条件向量

c = cache[clip_id] 或手写 style-only c
对照真实片段：从条件缓存里取该 clip 的真实 c 自由生成：只设 style 3D，其余保持零
I2 · DURATIONplanner head

预测原生时长

predict_contract_frame_count(model, ckpt, c)
只在没有参考帧数时才需要这一步 裁剪到训练数据支持的时长范围内
