先看这一页 · System boundary

ULA MMDiT V2：从文本生成整段上半身关节角轨迹

Qwen 在生成器上游理解文本；ULA 根据 264D 数值条件，从整段噪声生成 [T,15] 关节角轨迹。模型不是逐帧自回归，也不会在请求时检索一条相似动作。

每次推理需要查 dataset 吗？不需要。 产品推理没有 nearest-neighbor 搜索，也不把参考动作作为模型输入。训练得到的 prototype、style 与统计契约已经保存在 checkpoint 中。 当前代码在进程启动时仍读取一次 semantic_index.parquet 做 condition bank 构建与哈希校验；这是元数据依赖，不是逐请求动作检索。
Lifecycle

四个阶段，不要混在一起理解

dataset 只参与离线训练和评测。运行进程启动一次，每条指令只构建一次文本条件；冻结版内部执行 2 次 Qwen forward，LoRA 版把双指令合成 1 个 batch。最终轨迹再按 30Hz 从缓冲区读取。

01 · Offline 训练阶段 dataset → weights + contracts 输入真实动作、标签、style、噪声和 flow 时间 产出 generator best checkpoint 训练结束后不再逐条访问这些动作
02 · Once per process 启动加载 checkpoints + small metadata 加载 ULA、Qwen 基座与对应 adapter / LoRA 当前 LoRA loader 还会加载 Motion Metric checkpoint 读取 semantic index 校验 condition bank
03 · Once per prompt 单次生成 text → c → Euler ×32 → [T,15] 文本条件构建一次：冻结版 Qwen ×2；LoRA 版双指令 batch ×1 ULA 对整段序列执行 32 次 velocity-field forward 输出完整弧度制关节角轨迹
04 · T frames 30Hz 轨迹执行 buffer[k] every 1/30 s 播放阶段不再运行 Qwen 也不为每一帧重新调用 ULA 当前输出是目标关节角，不是力矩控制律
Execution frequency

“30Hz”指播放频率，不是模型推理频率

一次请求先把整条动作算完，再交给 MuJoCo 或机器人集成层。端到端生成耗时和 30Hz 轨迹采样是两个不同概念。

第 1 章 · End-to-end tensor trace

纯文本如何变成整段 15D 关节角轨迹

Qwen 位于 ULA 生成器外部，负责把自由文本翻译成结构化标签和动作语义条件。ULA 不直接读取字符串，只接收 Qwen 上游构造的 264D 条件 c。

Chapter 04 · Training

训练过程：先训练文本条件，再训练动作生成器

训练不是一次端到端更新。冻结版与 LoRA 版都分成两个阶段：先得到可用的文本条件组件，再固定文本侧并训练同一个 12.394M ULA MMDiT V2 生成器。

4.1
先区分两个版本确认哪些文本侧参数可训练，以及条件向量最后 128D 从哪里来。
4.2
训练文本条件组件冻结版训练 semantic adapter；LoRA 版训练跨模态 Qwen Motion LoRA。
4.3
训练 ULA 生成器固定文本侧，组装 264D 条件，用 Flow Matching、七项损失和 EMA 更新 ULA。
“冻结版”与“LoRA 版”都冻结 Qwen 基座：冻结版只训练小型 semantic adapter，并用标签查 128D group prototype；LoRA 版额外训练 Qwen 顶部四层的 LoRA，把每条文本映射为独立 128D motion latent。顶部的 12.394M 只统计两版共有的 ULA 生成器。

Chapter 06 · Evaluation

评测过程：先分清 objective，再看完整采样

teacher-forced test objective 与从纯噪声开始的 32 步完整采样回答不同问题。固定标签 K1 主要比较生成器条件质量，不等同于端到端文本分类能力。

当前结论：保留 baseline

Qwen LoRA 的 test objective 小幅改善 0.32%，但 canonical K1 的位置和动力学没有收益；使用严格未见中文改写时，位置 RMSE 显著恶化 4.33%。LoRA checkpoint 适合作为实验产物，暂不替换默认生成器。

A · Optimization metric Teacher-forced objective 在真实 noise-data 直线上做单步重建，固定重采样为 128 帧。适合训练选点，但不代表从纯噪声 rollout 的最终轨迹质量。
B · Generator A/B Canonical K1 sampling 162 条 test episode，固定真值 behavior / emotion、reference style、帧数、seed=7 和 32 sampling steps。比较两套生成器，不测试标签分类。
C · Text generalization Held-out Chinese K1 保持同一 reference 和采样协议，只把文本替换为 Qwen 训练未见的中文 test paraphrase，用于测量文本 latent 分布变化。
